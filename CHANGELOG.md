## 0.1.0

Initial version, prepared for first release.

- Read-only directory name audits with stable relative-path output.
- Windows device-name, forbidden-character, and trailing-space/period checks.
- NFC normalization and case-folded sibling collision checks.
- Configurable UTF-8 component and relative path length limits.
- Human and JSON command-line reports, plus a Python library API.
- Symlink, Windows reparse-point, and default `.git` exclusions.
